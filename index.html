Research

I am interested in natural language processing, language modeling (both large and small models), and deep learning in general. My PhD research studied vector retrieval as external memory for language models, both episodic memory of a long document the model is reading and semantic memory of general world knowledge. Both rest on Neurocache, which retrieves hidden states instead of text: it runs k-nearest-neighbor search over cached states at a middle layer of a frozen pre-trained model and passes what it finds to the upper layers through a separate cache-attention module. Against text retrieval, neither side wins everywhere: the cache loses open-web question answering, but wins lexical and structured lookup, and wins multi-hop questions for far less computation. A small model with this memory beats a larger model trained the same way on knowledge questions, and editing the store changes the model's answers with no weight update. Its main limitation is that it cannot tell when what it retrieved is wrong, or when the answer is absent.

From 2021 to 2024, I was also an active member of the Turkish Data Depository project, an open-source repository for data and tools for the Turkish language, where I managed TDD's dataset hub and oversaw Mukayese, a collection of Turkish language benchmarks.

Selected Publications & Projects
Neurocache: Efficient Vector Retrieval for Long-range Language Modeling
Ali Safaya, Deniz Yuret
NAACL 2024

ACL Anthology / arXiv / Code

Neurocache extends the effective context of large language models with an external vector cache of compressed past states, retrieved through efficient k-nearest-neighbor lookup and fused back into the attention layers.

Kanarya: An Open Turkish Language Model
Ali Safaya · Turkish Data Depository
2B-parameter Turkish LLM · Hugging Face

Model card

Kanarya is a 2-billion-parameter Turkish language model based on the GPT-J architecture, pretrained on large-scale filtered Turkish web text and released openly for Turkish text generation and NLP research.

Mukayese: Turkish NLP Strikes Back

Mukayese is a collection of NLP benchmarks for the Turkish language, consisting of seven leaderboards for different NLP tasks. For each benchmark, we work with one or more datasets and present two or more baselines.
